# FeelingBaisModule
所谓AI游戏的圣杯，就是让模型能够完全理解和制造体验。所以，这个模块是完全围绕着构建游戏和视听体验来进行开发的。

现在先开个头就好，先说说自己的想法。

首先，这是一个面向导演系统的Agent模型，它必须是天生多模态又不至于多模态。但总而言之，它的最低要求是，必须能够完完整整的导演出一部完全理解人类情绪，完全能够制造出体验的作品。
这里的体验首先我们可以做一轮划分，一个是交互式的游戏体验，一个是单向观看的影视体验。
我们默认的体验时长在输出阶段至少要能支撑120分钟（也就是一部电影），第二档标准是12集番剧240分钟，第三档标准是单机游戏30小时。
以上可以算是业务目标和业务需求，开发的时候需要时刻对齐的目标。

这是我的思路，而不一定是其他人的思路。所以我大致上会把体验的定义问题先说一下：

-体验首先是千人千面的，这是因为每个人的经验和认知都不同，甚至生理机能都会随着后天成长或者先天差异而不同。
-同一个人在不同时刻的体验也有可能会有所差异，假设用户是会随着现实世界的进行，信念发生变化的。
-但另一方面，提供体验的媒介（比如说这个模型）本身也在，也有能力改变用户的信念。
-体验归根到底是一种抽象的信念，它不是任何的输出模态，它可以对接到任何的模态上。
